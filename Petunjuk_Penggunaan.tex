\section{Pendahuluan}
Selamat datang di \textbf{CocokGak}, aplikasi web cerdas yang membantu Anda memadupadankan pakaian dengan gaya yang tepat. Aplikasi ini menggunakan teknologi Kecerdasan Buatan (AI) untuk memberikan analisis, rating, dan rekomendasi fashion berdasarkan item pakaian yang Anda miliki.

\section{Prasyarat Sistem}
Untuk menggunakan aplikasi ini dengan lancar, pastikan perangkat Anda memenuhi syarat berikut:
\begin{itemize}
    \item Perangkat Komputer/Laptop atau Smartphone.
    \item Koneksi Internet yang stabil.
    \item Web Browser modern (Google Chrome, Mozilla Firefox, Safari, atau Microsoft Edge).
\end{itemize}

\section{Langkah-langkah Penggunaan}

Ikuti langkah-langkah berikut untuk mendapatkan analisis fashion dari AI:

\subsection{1. Mengakses Aplikasi}
Buka aplikasi CocokGak melalui web browser Anda. Anda akan disambut dengan tampilan utama aplikasi.

\subsection{2. Langkah 1: Unggah Foto Item Pakaian}
Pada halaman awal, Anda diminta untuk mengunggah foto pakaian yang ingin dipadukan.
\begin{enumerate}
    \item Klik tombol \textbf{"+ Add Photo"} (Tambah Foto).
    \item Pilih foto dari galeri atau file komputer Anda.
    \item Jendela \textit{preview} akan muncul. Jika foto sudah sesuai, klik \textbf{"Add Item"}.
    \item Ulangi proses ini untuk item lain (misalnya: baju, celana, sepatu).
    \item Anda dapat mengunggah \textbf{hingga 5 item}.
    \item Jika ingin menghapus item, klik tombol \textbf{"X"} pada pojok kanan atas foto item tersebut.
    \item Setelah selesai memilih minimal 1 item, klik tombol \textbf{"NEXT: CHOOSE STYLE"} untuk melanjutkan.
\end{enumerate}

\subsection{3. Langkah 2: Pilih Target Gaya (Vibe)}
Pilih gaya atau \textit{vibe} yang ingin Anda tampilkan. Terdapat 4 pilihan gaya yang tersedia:
\begin{itemize}
    \item \textbf{Casual}: Santai dan nyaman (Relaxed \& Comfortable).
    \item \textbf{Sporty}: Aktif dan dinamis (Active \& Dynamic).
    \item \textbf{Formal}: Elegan dan profesional (Elegant \& Professional).
    \item \textbf{Streetwear}: Berani dan trendi (Bold \& Trendy).
\end{itemize}
Klik pada salah satu kartu gaya tersebut, kemudian klik tombol \textbf{"GENERATE MATCH ANALYSIS"} untuk memulai analisis.

\subsection{4. Langkah 3: Proses Analisis}
Tunggu beberapa saat sementara AI kami menganalisis kecocokan pakaian Anda dengan gaya yang dipilih. Durasi proses bergantung pada kecepatan internet Anda.

\subsection{5. Langkah 4: Melihat Hasil}
Setelah analisis selesai, Anda akan melihat halaman hasil yang menampilkan:
\begin{itemize}
    \item \textbf{Rating Bintang (1-5)}: Seberapa cocok pakaian Anda dengan gaya yang dipilih.
    \item \textbf{Ulasan Singkat}: Penjelasan mengenai tampilan Anda.
    \item \textbf{Saran Perbaikan}: Rekomendasi item tambahan atau pengganti untuk meningkatkan penampilan.
    \item \textbf{Mannequin Preview}: Visualisasi gabungan item pakaian Anda.
\end{itemize}

\subsection{Mengulang Proses}
Jika Anda ingin mencoba kombinasi lain, klik tombol \textbf{"Start New Match"} atau tombol Reset yang tersedia di bagian bawah halaman hasil.

\section{Tips untuk Hasil Terbaik}
\begin{itemize}
    \item Gunakan foto dengan pencahayaan yang cukup.
    \item Pastikan item pakaian terlihat jelas dan tidak terpotong.
    \item Unggah foto satu per satu item (misal: satu foto baju, satu foto celana) untuk akurasi lebih tinggi.
\end{itemize}
